# Triage this bug report

Read ./case.json and ./source/description.md, then classify.

Severity rubric: critical = data loss / security / payments / full outage;
high = core flow broken, no workaround; medium = degraded, workaround exists;
low = cosmetic, copy, minor UX.

Owner mapping: crashes/errors -> oncall · performance -> infra · copy/UI -> design.

`summary`: one sentence a reviewer can verify quickly.
